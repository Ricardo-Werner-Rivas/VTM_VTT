# *Vampire The Masquerade: Virtual TableTop*
A specialized VTT for *Vampire: The Masquerade* developed in Python.
## Intended features
### Release features
* Character sheet editor, for basic and supplementary sheets, for *Vampire: The Masquerade - 20th Aniversary Edition*.
* Compatibility with *Biblioteca Oscura* character sheets.
* Character sheets' and command dice rolls.
### Future features
* Support for all editions' character sheets.
* Map usual functions.
* Token creation and manipulation.
* Support for shared audio tracks.
## Distribution
The app is developed in Python using *NiceGUI* and compiled using *Nuitka* with the `--standalone` flag.
The resulting directory will be distributed through the repository's releases page.
